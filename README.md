# Lilt

A tiny programming language whose front-end is your voice.

Submission-in-progress for the DEV [Build with Gemma 4](<https://dev.to/devteam/join-the-gemma-4-challenge-3000-prize-pool-for-ten-winners-23in>) challenge (May 6–24, 2026).
Started: May 8, 2026.

## What it is

Hum, beatbox, sing, or play a phrase. Lilt turns it into a short, human-readable program. Edit the program. Hear the result. Share the text.
