What is this?

      

        Hum, beatbox, whistle, or play a phrase. Lilt turns it into a short,
        human-readable program. Edit the program. Hear the result. Share the
        text.
      

      

        Built for the Gemma 4 challenge by Brooke Chauntel. The model and
        the audio pipeline live offline; this page is the in-browser preview.
      

      

        See the code on GitHub »
